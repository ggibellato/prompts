## Base

The [base folder](base/README.md) contains foundational prompt components that define core behaviors, discovery processes, and specialized roles for AI-assisted development. This includes behavior rules, discovery phase guidelines, role-specific prompts, and specialized subagent configurations.

## Templates

The [templates folder](templates/README.md) contains reusable prompt templates for different AI agent architectures, including orchestrator, specialist, and workflow prompts. These templates provide structured approaches for building AI systems with specialized roles and coordinated task execution.
