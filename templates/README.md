# Prompt Templates

This folder contains various prompt templates for different AI agent architectures.

## Available Templates

### [Orchestrator Prompt](orchestrator.md)
An orchestrator prompt is designed for coordinating and managing multiple specialized agents or tasks. It acts as a central controller that breaks down complex problems, delegates work to appropriate specialists, and synthesizes results into cohesive solutions. The orchestrator handles high-level planning, task distribution, and ensures all components work together effectively.

### [Specialist Prompt](specilist.md)
A specialist prompt is focused on performing specific, well-defined tasks within a particular domain or skill area. Specialists have deep expertise in their designated area and provide detailed, accurate responses for their specialized function. They work independently or as part of a larger system coordinated by an orchestrator.

### [Workflow Prompt](workflow.md)
A workflow prompt defines structured, step-by-step processes for completing tasks in a systematic manner. It establishes clear sequences of actions, decision points, and transitions between different stages of work. Workflow prompts ensure consistency, repeatability, and proper execution order for multi-step operations.
