# Subagent Prompts

This folder contains specialized agent prompts for specific tasks within a larger development workflow. These subagents handle focused responsibilities and can be invoked by orchestrator agents.

## Available Subagents

- **[code-implementation-agent.md](code-implementation-agent.md)** - Implements code changes based on approved implementation plans
- **[codebase-analyzer-agent.md](codebase-analyzer-agent.md)** - Discovers and documents existing patterns in a codebase before new feature implementation
