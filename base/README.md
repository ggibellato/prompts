# Base Folder Documentation

The `base` folder contains foundational prompt experiments and reusable prompt components. These are designed to serve as building blocks for more complex prompt workflows and agent behaviors.

## Purpose
This folder is a collection of experiments and templates aimed at creating modular, reusable prompts for various agent roles and workflows. The goal is to streamline prompt engineering by providing a set of well-documented, adaptable prompt assets.

## Structure
- **behaviour.md**: Defines general behavioral guidelines or patterns for agents.
- **discovery-phase.md**: Contains prompts or templates for the discovery or information-gathering phase of an agent's workflow.
- **role/**: Contains role-specific prompt templates:
  - **csharp-react.md**: Prompts for agents working with C# and React.
  - **csharp.md**: Prompts for agents focused on C#.
  - **react.md**: Prompts for agents focused on React.
- **subagents/**: Contains prompt templates for specialized sub-agents, such as:
  - **codebase-analyzer-agent.md**: Prompts for agents that analyze codebases.

## Usage
Use these files as starting points or modules when constructing new agent prompts or workflows. They are intended to be copied, adapted, or referenced as needed to accelerate prompt development and ensure consistency across projects.

---
*This folder is experimental and may evolve as new reusable prompt patterns are discovered.*
